# 날짜 선택으로 과거 사진 보기

## 사용자 결과

날짜를 선택하면, 그 날짜의 NASA APOD(사진 또는 영상)와 설명을 오늘 사진과 같은 방식으로 볼 수 있다.

## 승인된 범위

- 날짜를 고를 수 있는 입력을 화면에 보여준다. 고를 수 있는 범위는 1995-06-16부터 오늘까지로 제한한다.
- 날짜를 선택하면 그 날짜의 NASA APOD 데이터를 가져와, 오늘 사진과 동일한 방식(사진/영상/설명/실패 안내)으로 보여준다.
- 날짜를 선택하지 않은 기본 화면은 지금처럼 오늘 날짜를 보여준다 — 기존 동작을 그대로 유지한다.
- 선택한 날짜는 주소(URL)에 반영되어, 새로고침하거나 그 주소를 다시 열어도 같은 날짜가 다시 보인다.

## 관찰 가능한 수용 기준

- 실제 브라우저에서 날짜 입력을 과거의 특정 날짜로 바꾸면, 그 날짜의 실제 NASA 데이터(사진 또는 영상, 설명)로 화면이 바뀐다.
- 날짜를 선택하지 않고 처음 열면 오늘 데이터가 그대로 보인다.
- 날짜 입력에서 1995-06-16 이전이나 오늘 이후는 고를 수 없다.
- 선택한 날짜로 새로고침하거나 그 주소를 다시 열면 같은 날짜의 데이터가 다시 보인다.
- 요청이 실패하면 기존과 동일하게 실패 안내가 보인다 — 잘못된 날짜로 인한 실패도 동일하게 처리된다.

## 설정된 제약과 근거

- NASA APOD API는 `date` 파라미터(YYYY-MM-DD)를 지원하며 유효 범위는 1995-06-16부터 오늘까지다. 근거: [github.com/nasa/apod-api](https://github.com/nasa/apod-api) 공식 문서([docs/specs/today-apod-photo/spec.md](../today-apod-photo/spec.md)에서 이미 확인).
- 날짜 상태는 주소(URL)에 반영한다. 기존 아키텍처(서버 컴포넌트에서 직접 fetch)를 그대로 유지하면서, 추가 구조 변경 없이 새로고침·링크 공유가 가능해지기 때문이다.

## 가정

- 날짜를 고르는 화면 요소는 브라우저 기본 날짜 입력(`<input type="date">`)을 사용한다. 더 보기 좋은 달력 UI가 필요해지면 이 부분만 바꾸면 된다.
- 잘못되었거나 범위 밖의 날짜가 주소로 직접 들어와도 기존 실패 안내 화면을 그대로 재사용한다 — 별도의 안내를 새로 만들지 않는다.

## 범위 밖 (이유)

- 즐겨찾기, 키워드 검색: 여전히 다음 결과로 미룸 — [docs/specs/today-apod-photo/spec.md](../today-apod-photo/spec.md)와 동일한 이유.
- AI 기반 쉬운 설명: 여전히 다음 확장으로 미룸 — [docs/decisions/apod-explanation-language.md](../../decisions/apod-explanation-language.md) 참고.
- "이전 날/다음 날" 같은 순차 탐색 버튼: 이번 결과는 날짜를 직접 선택하는 것만 다룬다. 필요해지면 별도 결과로 다룬다.

## 남은 위험

- 1995-06-16 이후 기간 중 실제로 결측된 날짜가 있는지는 확인하지 않았다. 있다면 기존 실패 안내로 처리되지만, 사용자에게는 "그 날은 없다"는 게 아니라 일반적인 "가져오지 못했다"는 안내로 보인다.
