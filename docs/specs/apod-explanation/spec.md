# 오늘의 우주 사진 설명 보여주기

## 사용자 결과

사이트를 열면 오늘의 우주 사진(또는 영상)과 함께, NASA가 그날 올린 설명 글을 볼 수 있다.

## 승인된 범위

- 오늘 데이터를 성공적으로 가져왔을 때, NASA APOD가 제공하는 설명(`explanation`) 텍스트를 사진(또는 영상)·제목과 함께 화면에 보여준다.
- 사진인 날과 영상인 날 모두에 적용한다 — 설명은 media_type과 무관하게 항상 존재한다.

## 관찰 가능한 수용 기준

- 실제 브라우저로 페이지를 열었을 때, 오늘 사진(또는 영상)과 함께 NASA가 제공한 설명 텍스트가 화면에 나타난다.
- 설명은 번역이나 재작성 없이 NASA API가 반환한 원문 그대로 보인다.
- API 요청이 실패했을 때의 기존 동작(실패 안내만 표시)은 그대로 유지된다 — 실패 시에는 설명 자체가 없으므로 추가로 보여줄 것이 없다.

## 설정된 제약과 근거

- 이 결과는 [PRODUCT.md](../../../PRODUCT.md)의 "설명은 초등학생 눈높이에서 어렵지 않게 풀어써야 한다"는 경험 원칙을 아직 충족하지 못한다. 그 원칙을 채우려면 AI(LLM) 기반 번역·재작성이 사실상 유일한 방법인데, Anthropic API 키 발급에 결제 수단 등록이 필요해 지금 단계에서는 설정 부담이 실익보다 크다고 판단해 제외했다. 이 판단과 재검토 조건은 [docs/decisions/apod-explanation-language.md](../../decisions/apod-explanation-language.md)에 남겨 두었다.

## 가정

- 설명 텍스트는 NASA가 준 그대로(영어) 노출하며, 별도 요약이나 길이 제한을 두지 않는다.

## 범위 밖 (이유)

- AI 기반 쉬운 설명(번역·재작성): 다음 확장으로 미룸. 이유와 재검토 조건은 `docs/decisions/apod-explanation-language.md` 참고.
- 날짜 선택으로 과거 사진 보기, 즐겨찾기, 키워드 검색: 여전히 범위 밖 — [docs/specs/today-apod-photo/spec.md](../today-apod-photo/spec.md)와 동일한 이유로 다음 결과들로 미룬다.

## 남은 위험

- 대상 사용자(초등학생)에게 영어 설명은 읽기 어려워, "설명을 통해 흥미를 증폭시킨다"는 PRODUCT.md의 약속은 이번 결과로는 채워지지 않는다. 사진·영상 감상 자체는 유지되므로 핵심 재미 요소는 남아 있다.
