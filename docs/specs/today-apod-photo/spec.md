# 오늘의 우주 사진 보기

## 사용자 결과

사이트를 열면 별도 조작 없이 오늘 날짜의 NASA APOD(오늘의 우주 사진)와 제목을 바로 볼 수 있다.

## 승인된 범위

- 페이지 진입 시 자동으로 NASA APOD API에서 오늘 날짜 데이터를 가져온다.
- 사진(이미지)과 제목을 화면에 보여준다.
- 데이터를 가져오는 동안에는 로딩 상태를 보여준다.
- API 요청이 실패하면(네트워크 오류, 키 오류 등) 실패했음을 알리는 안내를 보여준다.
- 오늘의 항목이 사진이 아니라 영상(media_type=video)이면, 그 영상을 화면에서 바로 볼 수 있게 보여준다.

## 관찰 가능한 수용 기준

- 실제 브라우저로 페이지를 열었을 때, 오늘 날짜의 실제 NASA APOD 이미지와 제목이 화면에 나타난다.
- 로딩 중에는 빈 화면이 아니라 로딩 상태가 보인다.
- API 키가 없거나 잘못되었을 때, 또는 네트워크 요청이 실패했을 때 빈 화면이 아니라 실패 안내가 보인다.
- 오늘 항목의 media_type이 video일 때, 그 영상이 화면에서 바로 재생 가능한 형태로 보인다.
- media_type이 image도 video도 아닌 예기치 못한 값일 때는, 빈 화면 대신 안내 문구를 보여준다.

## 설정된 제약과 근거

- NASA APOD API(`GET /planetary/apod`, `date` 기본값 오늘)를 사용한다. 근거: [github.com/nasa/apod-api](https://github.com/nasa/apod-api) 공식 문서에서 확인.
- API 키는 코드에 하드코딩하지 않고 설정(환경 변수 등)으로 주입한다. 근거: NASA API의 `DEMO_KEY`는 요청 제한이 낮아 안정적인 개발·검증에 부적합하므로, 개인 키(api.nasa.gov에서 무료 즉시 발급) 사용을 전제로 한다.
- 대상 사용자가 초등학생인 [PRODUCT.md](../../../PRODUCT.md)의 "쉬운 설명" 원칙은 이 결과에 적용하지 않는다. 이 결과는 사진·제목 노출만 다루고, 설명(explanation) 자체를 화면에 표시하지 않는다.

## 가정

- 제목(title)은 NASA API가 반환하는 원문(주로 영어) 그대로 보여준다. 초등학생 눈높이 번역은 다음 결과(쉬운 설명)에서 다룬다.
- 날짜는 항상 "오늘"(서버/클라이언트 기준 현재 날짜)만 다루며, 별도의 시간대 정책은 정하지 않는다.

## 범위 밖 (이유)

- 날짜 선택으로 과거 사진 보기: 다음 결과로 미룸. 이 결과는 "오늘 사진 노출"이라는 가장 좁은 단위만 검증한다.
- 즐겨찾기: 다음 결과로 미룸. 오늘 사진 노출이 먼저 안정적으로 동작해야 저장할 대상이 생긴다.
- 키워드 검색: 다음 결과로 미룸. 검색 대상이 되는 화면(날짜별 조회)이 아직 없다.
- 쉬운 설명(번역·AI 재작성): 다음 결과로 미룸. AI 호출이라는 별도 기술 요소가 필요해, 사진 노출과 분리해야 각각 한 번에 구현하고 검증하기 쉽다.

## 남은 위험

- NASA API의 DEMO_KEY는 실제로 시간당 요청 제한에 금방 도달하는 것을 개발 중 확인했다(429 응답). 개인 API 키를 쓰더라도 제한에 걸릴 가능성은 남아 있다.
- 영상은 NASA가 제공하는 `url`을 그대로 화면에 붙여 보여준다. 실제 확인해보니 이 url은 유튜브 등 외부 플랫폼의 embed 링크일 수도 있고, apod.nasa.gov가 직접 호스팅하는 영상 파일(mp4 등)일 수도 있다. 외부 플랫폼 embed인 경우, 그 플랫폼이 영상 재생 화면에 추천 영상 등 NASA가 선별하지 않은 부가 콘텐츠를 노출할 수 있다. 초등학생 대상 서비스라는 점에서, 이 부가 노출을 더 통제할지는 다음 결과에서 판단이 필요할 수 있다.
