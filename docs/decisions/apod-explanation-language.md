# APOD 설명 텍스트 언어

## Decisions

- 오늘의 우주 사진/영상과 함께 보여주는 설명(explanation)은 NASA가 제공하는 원문(영어) 그대로 노출한다. 번역이나 초등학생 눈높이 재작성은 하지 않는다.

## Boundaries

- 이 결정은 오늘의 우주 사진 서비스에서 NASA APOD의 `explanation` 필드를 다루는 모든 화면에 적용된다.
- `PRODUCT.md`의 "쉬운 설명" 경험 원칙 자체를 취소하는 것은 아니다 — 그 원칙을 채우는 방법(AI 기반 번역·재작성)을 지금 도입하지 않기로 한 것뿐이다.

## Why

"쉬운 설명"(번역 + 초등학생 눈높이 재작성)을 실질적으로 만족시키는 방법은 AI(LLM) 기반 재작성이 사실상 유일하다 — 기계 번역만으로는 전문 용어가 그대로 남아 눈높이 문제를 풀지 못한다. 그런데 Anthropic API 키 발급에는 결제 수단 등록이 필요해, NASA 키처럼 가입만으로 바로 되는 게 아니다. 사용자가 이 설정 부담을 지금 감수할 가치가 없다고 판단해, 우선 원문을 그대로 노출하기로 했다.

## Reconsider when

- 사용자가 Anthropic API 결제 수단을 등록할 준비가 되었을 때.
- 원문(영어) 노출이 실제 사용 중 문제로 확인될 때(예: 아이가 흥미를 잃음).

## Still-rejected alternatives

- 기계 번역(AI 아닌 번역 API, 예: 파파고)만 적용 — 한국어로는 바뀌지만 전문 용어가 그대로 남아 "쉬운 설명"의 눈높이 재작성 목표를 채우지 못한다; 눈높이 문제보다 언어 장벽만이라도 우선 풀고 싶어지면 재검토한다.
