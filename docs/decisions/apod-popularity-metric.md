# APOD 인기도(조회수·다운로드 수) 표시

## Decisions

- 조회수·다운로드 수 등 인기도 기준으로 날짜를 보여주는 기능은 넣지 않는다.

## Why

NASA APOD API 공식 문서를 확인한 결과, 응답에 조회수·다운로드 수·인기도·순위 관련 필드가 전혀 없다(`title`, `date`, `url`, `hdurl`, `media_type`, `explanation`, `copyright`, `concept_tags`, `thumbnail_url` 등 12개 필드뿐). NASA가 이 데이터를 제공하지 않아 "NASA 기준 인기 날짜"는 만들 수 없다.

대안으로 "이 앱 사용자들의 즐겨찾기 횟수"를 인기도로 쓰는 방법을 검토했지만, 여러 사용자의 즐겨찾기를 합산하려면 계정·서버 저장이 필요해 PRODUCT.md가 이미 범위 밖으로 정한 "여러 사용자 계정" 영역을 건드리게 되어 제외했다.

## Reconsider when

- NASA APOD API가 조회수·인기도 관련 필드를 추가로 제공하게 될 때.
- 여러 사용자 계정·서버 저장을 도입하기로 방향이 바뀔 때(그때 "우리 서비스 안에서의 인기"를 다시 검토할 수 있다).

## Still-rejected alternatives

- 이 앱 사용자들의 즐겨찾기 횟수를 집계해 "인기 날짜"로 보여주기 — 계정 없는 로컬 저장 방식과 맞지 않고, 여러 사용자 데이터를 모으려면 서버 저장·계정 체계가 필요해 범위 밖.
